# Semi-flexible-bus-computational-results

This repository contains the benchmark instances and computational results used in the numerical experiments of a semi-flexible demand-responsive transit study.

## Contents

- `instances/`: Leuven real-network and random-network instances.
- `table5_prebooking/`: results for the online pre-booking acceptance phase.
- `table6_reoptimization/`: results for the offline booking cut-off re-optimization phase.
- `table7_realtime_control/`: results for the day-of-operations real-time control phase.
- `table8_static_reference/`: static full-information LNS reference results.
